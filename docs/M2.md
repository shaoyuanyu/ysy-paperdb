# M2 实现说明：采集、导入、去重与 enrich

> 2026-11-24 · paperdb 0.2.0

## 已实现

| 能力 | 说明 |
|---|---|
| `POST /v1/resolve` | DOI / arXiv / ACL Anthology / OpenReview / DBLP / 标题解析预览，不写库 |
| 元数据源 | Crossref、arXiv、DBLP（search + record XML）、OpenAlex、Semantic Scholar、ACL Anthology `.bib`、OpenReview API v2 |
| 字段合并 | 主源优先 + DBLP venue/作者 ID 增强 + 多源作者 ID 合并 |
| venue 归一 | 库内 DBLP/名称/别名精确匹配 + 会议 proceedings 前缀 + 大写缩写匹配 |
| 评价 | resolve 预览直接显示 CCF/CAS（按 `valid_from` / fallback） |
| 导入 | `POST /v1/imports/identifiers`、`POST /v1/imports/bibtex`（multipart）；逐条状态/重试/取消 |
| 任务队列 | Postgres `job` 表 + `paperdb worker`；claim `SKIP LOCKED`、心跳、重试/死信、lease 回收 |
| BibTeX | 自解析（nested braces / quoted / concat），保留 citekey（冲突时自动降级） |
| 去重 | 标题相似度 + 年份邻近 + 第一作者；`GET /papers/{id}/duplicates` |
| 合并 | `POST /papers/{id}/merge`（identifiers/作者/状态/重定向）；旧 ID 解析到 survivor |
| enrich | `POST /papers/{id}/enrich` 入队；按 DOI/arXiv/标题刷新，不覆盖 `userLockedFields` |

## 验证
