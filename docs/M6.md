# M6 实现说明：引用图数据与查询

> 2026-11-25 · paperdb 0.6.0

## 已实现

| 能力 | 说明 |
|---|---|
| 数据模型 | `citation_edge`（库内→库内，唯一/自环约束）、`external_work`（库外 stub）、`external_citation`（cites/cited_by）、`citation_stat`（OpenAlex 计数快照） |
| 同步 | `sync_citations` job；按 DOI/OpenAlex 找 work，写 `referenced_works` 出边与 `cites:W...` 入边 |
| 库内解析 | 按 OpenAlex ID/DOI 把外部作品回填成库内论文并写 `citation_edge`；未命中保留 `external_work` stub |
| API | `GET /papers/{id}/references`、`GET /papers/{id}/citations`、`POST /citations/sync`（admin） |
| 前端 | 详情页展示参考文献/被引列表；库内条目可点，库外优先按 DOI 外链 |
| 增量 | 论文记录 `citations_synced_at`；同步接口不传 paperIds 时只取未同步论文（最多 500） |

## 验证

- `pytest -q`：48 passed（mock OpenAlex：A 引用 B，同时产生库外 stub；B 的被引列表包含 A）
- `ruff` / `pyright` / `alembic check`：clean
- 真实 OpenAlex 同步未在离线沙箱跑；上线后手动触发一次
  `POST /v1/citations/sync`，随后检查 `/v1/papers/{id}/references`。
