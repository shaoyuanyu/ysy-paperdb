# M4 实现说明：PDF、全文、批注

> 2026-11-24 · paperdb 0.4.0

## 已实现

| 能力 | 说明 |
|---|---|
| 上传 | `POST /papers/{id}/files` multipart；`%PDF-` magic、200MB 上限、sha256 内容寻址、同论文秒传 |
| 存储 | 本地 `pdf_file.storage_key`；多论文可共享 blob；软删 + 主文件提升 + `gc_blob` 延迟回收 |
| 抽取 | `extract_pdf` worker：PyMuPDF 逐页文本 + 页数 + 中/英语言粗判；重抽取清旧页 |
| 全文 | `pdf_page_text.tsv`（english FTS）+ pg_trgm 兜底；`GET /files/{id}/search`、`GET /search/fulltext` |
| 读取 | `GET /files/{id}/content` 支持 `Range` 206 + `Content-Range` / `ETag` 风格头；私密流式读取 |
| 批注 | 新建/列表/改/软删；页码 + 0–1 rects + quote/prefix/suffix；颜色/评论/`anchorStatus` |
| 计数 | `PaperSummary.counts.pdfFiles/annotations` 来自 SQL 聚合，不再是占位 0 |
| 运维 | 删除文件入队 `gc_blob`；worker 对未删除引用计数为 0 才删 blob |

## 验证

- `pytest -q`：47 passed（真实上传 PDF + worker 抽取 + 正文搜索 + Range + 批注 CRUD）
- `ruff` / `ruff format --check` / `pyright`：clean
- `alembic check`：no drift

## 许可

PyMuPDF 采用 **AGPL-3.0**（商业闭源分发需 Artifex 商业许可）。本项目按私有、自托管、
不对外分发镜像/服务的方式使用；若未来要把 paperdb 镜像或 SaaS 对外提供，需先评估并
替换为宽松许可的抽取方案（如 pdfminer.six / pypdf）或购买许可。CCF/CAS 数据同样只随
私有部署导入，不进入公共镜像。
