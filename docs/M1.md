## M1 的明确偏差

- **venue/author 没有 delete**：避免误删引用链；删除/合并留到 M2/M3。
- **export token 只有 `library` / `paper` 范围**：collection/project/view 范围等 M3/M5。
- **没有 jobs/worker**：resolve/enrich/extract 都要等 M2/M4；M1 不建任务表。
- **没有 PDF、annotations、collections/tags/views、search/fulltext**：按设计 M2–M5。
- **没有 `/v1/settings`、`/v1/tokens` 之外的 admin UI**：维护走 CLI。
- `PAPERDB_PUBLIC_URL` 未设置时导出链接指向 `127.0.0.1`，生产 compose 已默认 `library.shaoyuanyu.cn`。
