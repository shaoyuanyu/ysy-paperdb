# M3 实现说明：组织、视图、项目与自动规则

> 2026-11-24 · paperdb 0.3.0

## 已实现

| 能力 | 说明 |
|---|---|
| 集合 | 层级树、同级重名保护、移动防环、promote/discard 删除、加/移/重排论文、递归计数 |
| 标签 | 命名空间层级路径（`topic/llm/rag`、`status:needs-review`）、自动建祖先、path 不可变/仅改展示名、合并（迁移关系并重写视图/规则 JSON）、删除保护 |
| 智能视图 | 保存 Filter DSL、排序/列、置顶、计数；`GET /papers?view=` 直接消费 |
| Filter DSL | 元数据/年份/kind/CCF/CAS/标签/集合/作者/阅读状态/日期/标识符；all/any + groups；字段/操作符白名单；`POST /views/validate` |
| 项目 | 集合范围（含子集合）、置顶论文、citekey 模板、导出选项；并集计数与分页列表 |
| 自动规则 | 条件 + 白名单动作（进集合/打标签/设状态）、手动回放、`lastRunAt` |
| 批量编辑 | `PATCH /papers/bulk`：加/删标签、加/删集合、状态/评分/星标 |
| 论文成员关系 | 单条 `POST/DELETE /papers/{id}/tags`、`.../collections`；摘要带 `tags`/`collections` |

## 验证

- `pytest -q`：46 passed
- `ruff` / `ruff format --check` / `pyright`：clean
- `alembic check`：no drift
- 覆盖：集合树+递归计数、跨集合移动防环、标签层级/改名/合并、视图计数与过滤列表、项目并集、自动规则回放、批量编辑

## 明确未做

- 自动规则在 **import/create 时自动执行**：目前只支持手动 `apply`，接入导入管道放在 M5 前补。
- 集合/标签的拖拽排序 API 只有 `reorder`，前端交互在 M5。
- 视图列宽/密度等 UI 偏好只存 `columns` 字符串数组，细则由前端 localStorage 管。
- 项目级 export token / 范围导出：等 M5 前端设置页一起补。
